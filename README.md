# 🛍️ Retail Sales Analytics Project

This project showcases advanced SQL and data analytics skills applied to a retail sales dataset. The workflow includes building and managing a retail database, performing data cleaning and transformation, and conducting exploratory data analysis (EDA) to identify key sales trends, customer behavior patterns, and performance insights.The findings are then visualized through an interactive Power BI dashboard, providing dynamic and data-driven insights to support business decision-making. The dashboard highlights metrics such as total sales, profit margins and top-selling products enabling clear and actionable insights for stakeholders.

## 🎯 Objectives

- Build a retail sales database using SQL.
- Clean and transform raw sales data.
- Perform EDA to uncover sales trends and customer behavior.
- Visualize insights using Power BI for better decision-making.

## 📊 Key Insights

- Identified top-selling products and profitable regions.
- Analyzed monthly sales trends and seasonal demand.
- Built dynamic Power BI visuals for real-time decision support
